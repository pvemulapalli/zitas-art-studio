# About reference source

This is the actual Claude Design source of the approved page, unmodified. **REFERENCE ONLY.** Translate it into Liquid sections, blocks and snippets. Don't ship it.

- Open `source/About.dc.html` through a local static server (for example `npx serve source`), not file://. It loads `support.js` and the sibling .dc.html components.
- Use the Desktop / Mobile toggle in the top prototype bar. The mobile composition renders inside a phone frame.
- The prototype bar links to other pages that aren't in this package. Ignore them.
- Fonts load from Google Fonts (Marcellus, Mulish). Icons come from the Lucide CDN.
- Inline styles in the source are the exact values. The handoff Markdown is the authoritative explanation of them.
